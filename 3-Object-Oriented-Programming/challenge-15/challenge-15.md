# Challenge 15: University Course Information System

## Introduction

Educational institutions manage a large amount of information about the courses
they offer. Each course includes details such as its title, instructor,
schedule, classroom, credits, enrolled students, and learning objectives.

In JavaScript, this type of structured information is commonly represented using
**objects**, allowing related data to be grouped into a single, organized
entity.

In this challenge, you will practice **object modeling and abstraction** by
creating a JavaScript object that represents a university course.

---

## Problem Description

A university is developing a Course Management System to organize and manage its
academic programs.

Your task is to create a JavaScript object that models a single university
course. Before writing code, think about what information students,
administrators, and instructors need to know about a course.

Then, organize that information using meaningful properties and appropriate data
types.

---

## Requirements

Create a JavaScript object that satisfies the following requirements.

1. The object must represent **one university course**.

2. Include **between 12 and 20 meaningful properties**.

3. Include at least:

   - one nested object
   - one array property

4. Use appropriate data types:

   - strings
   - numbers
   - booleans
   - arrays
   - objects

5. Follow JavaScript naming conventions:

   - use camelCase
   - use descriptive property names

---

## Suggested Information

Your object may include information such as:

- courseCode
- courseName
- department
- instructor
- credits
- semester
- academicYear
- classroom
- maximumStudents
- enrolledStudents
- isOnline
- prerequisites
- topics
- schedule
- gradingPolicy
- textbook
- durationWeeks
- language

You may include additional properties if they improve the design.

---

## Expected Output

Your solution should contain:

- One well-structured JavaScript object
- Clear indentation and formatting
- Logical grouping of related information

---

## Evaluation Criteria

Your solution will be evaluated based on:

- Proper object organization
- Appropriate abstraction of a university course
- Meaningful property names
- Correct use of JavaScript data types
- Readable and maintainable code

---

## Bonus (Optional)

Enhance your solution by adding:

- A method that returns a formatted course summary
- Multiple nested objects (for example, instructor and schedule)
