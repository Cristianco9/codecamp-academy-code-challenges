# Code Challenge: Create a Student Profile Page

## Challenge Overview

In this challenge, you will create a student profile page using HTML
and CSS.

The goal is to practice building a complete web page, organizing
content with semantic HTML elements, and applying styles using CSS
class selectors.

You will create a profile page that introduces a student and describes
their learning goals in web development.

---

## Learning Objectives

By completing this challenge, you will practice:

* Creating a complete HTML document
* Linking an external CSS file
* Using semantic HTML elements
* Applying styles with CSS classes
* Working with colors and typography
* Organizing content into sections
* Creating a clean page layout

---

## Requirements

Create the following files:

```text
index.html
challenge-8.css
```

---

## HTML Structure

Build a student profile page containing the following sections.

### Header

The header must contain:

1. A student's full name

Example:

```text
Alex Johnson
```

2. A short professional or academic title

Example:

```text
Web Development Student
```

Use the following classes:

```text
header
title
subtitle
```

---

## Main Content

Create a main section containing two sections.

### About Me Section

Include:

1. A heading titled:

```text
About Me
```

2. Two paragraphs describing:

* Who you are
* What you are currently learning
* Your interests in technology
* Your learning experience

Use the classes:

```text
section
section-title
text
```

---

### Goals Section

Include:

1. A heading titled:

```text
Goals
```

2. A paragraph explaining your future goals.

Examples:

* Becoming a software developer
* Learning new technologies
* Building web applications
* Working on real-world projects

Use the classes:

```text
section
section-title
text
```

---

## Footer

Create a footer containing:

* A copyright message

Example:

```text
© 2026 Student Profile
```

Use the classes:

```text
footer
footer-text
```
