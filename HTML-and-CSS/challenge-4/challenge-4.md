# Code Challenge: Create an Artificial Intelligence Blog

## Challenge Overview

In this challenge, you will create a simple HTML blog page about
Artificial Intelligence (AI).

The goal is to practice using semantic HTML elements, images, lists,
tables, paragraphs, and page structure while creating an informative
blog article.

You must recreate the blog page and organize the content using the
appropriate HTML elements.

---

## Learning Objectives

By completing this challenge, you will practice:

* Creating a complete HTML document
* Using semantic HTML elements
* Working with images
* Creating unordered and ordered lists
* Building tables
* Using headings and paragraphs
* Organizing content with sections
* Creating a simple blog layout

---

## Requirements

Create a file named:

```text
index.html
```

Build a blog page about Artificial Intelligence containing the
following sections.

---

## Header Section

Inside the `<header>` element, add:

1. A main heading with the title:

```text
Artificial Intelligence
```

2. The author's name.

3. The publication date.

4. An image related to Artificial Intelligence using:

```html
<picture>
    <img>
</picture>
```

---

## Section 1: What Is AI?

Create a section containing:

1. A heading titled:

```text
What Is AI?
```

2. A paragraph explaining what Artificial Intelligence is.

3. An image related to AI systems.

---

## Section 2: Where Is AI Used?

Create a section containing:

1. A heading titled:

```text
Where Is AI Used?
```

2. An unordered list with at least five AI applications.

Examples:

* Virtual assistants
* Medical diagnosis
* Self-driving cars
* Facial recognition
* Content recommendations

---

## Section 3: AI Technologies

Create a section containing:

1. A heading titled:

```text
AI Technologies
```

2. A table with two columns:

* Technology
* Example

3. Include at least three technologies.

Examples:

| Technology       | Example         |
| ---------------- | --------------- |
| Machine Learning | Recommendations |
| Computer Vision  | Face Detection  |
| NLP              | Chatbots        |

---

## Section 4: Why Learn AI?

Create a section containing:

1. A heading titled:

```text
Why Learn AI?
```

2. Two paragraphs explaining:

* Why AI is important
* How AI is used in modern applications

---

## Section 5: Getting Started

Create a section containing:

1. A heading titled:

```text
Getting Started
```

2. An ordered list describing the first steps to learn AI.

Include at least three steps.

Examples:

1. Learn basic programming
2. Study basic math
3. Practice with small projects

---

## Footer Section

Create a footer containing:

* A copyright message
* The current year

Example:

```text
© 2025 AI Blog
```

---

## Technical Requirements

Your solution must use:

* `<html>`
* `<head>`
* `<body>`
* `<header>`
* `<main>`
* `<section>`
* `<footer>`
* `<h1>` to `<h2>`
* `<p>`
* `<strong>`
* `<cite>`
* `<picture>`
* `<img>`
* `<ul>`
* `<ol>`
* `<li>`
* `<table>`
* `<tr>`
* `<th>`
* `<td>`

## Expected Outcome

When the page is opened in the browser, users should see:

* A blog title and author information
* Images related to AI
* Information about Artificial Intelligence
* A list of AI applications
* A table of AI technologies
* Reasons to learn AI
