# Code Challenge: Style a Personal Profile Page with CSS

## Challenge Overview

In this challenge, you will build a simple personal profile page using
HTML and CSS.

The goal is to practice connecting an external stylesheet, using CSS
classes, and applying basic styles such as colors, fonts, alignment,
and sizing.

You will create a profile page that introduces a person and highlights
their goals as a future web developer.

---

## Learning Objectives

By completing this challenge, you will practice:

* Creating a simple HTML page
* Linking an external CSS file
* Using CSS class selectors
* Changing text colors
* Setting background colors
* Adjusting font sizes
* Aligning text
* Organizing page content with sections

---

## Requirements

Create the following files:

```text
index.html
challenge.css
```

---

## HTML Structure

Build a profile page containing the following sections.

### Header

The header must contain:

1. A person's name

Example:

```text
Jane Doe
```

2. A professional title

Example:

```text
Junior Web Developer
```

Use the following classes:

```text
header
title
subtitle
```

---

## Main Content

Create a main section containing two content sections.

### About Section

Include:

* A heading titled "About"
* A short paragraph introducing the person

Use the classes:

```text
section
section-title
text
```

---

### Goals Section

Include:

* A heading titled "Goals"
* A paragraph describing future goals

Use the classes:

```text
section
section-title
text
```

---

## Footer

Create a footer containing:

* A copyright message

Example:

```text
© 2026 Profile Page
```

Use the classes:

```text
footer
footer-text
```
