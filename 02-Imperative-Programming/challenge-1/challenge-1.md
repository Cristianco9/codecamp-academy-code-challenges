# JavaScript Challenge 1: Even or Odd Number

## Challenge Overview

In this challenge, you will create your first JavaScript program using:

* Variables
* User input
* Conditional statements
* Arithmetic operators

The HTML file has already been provided.

Your task is to create the JavaScript file that asks the user for a
number and determines whether it is even or odd.

---

## Learning Objectives

By completing this challenge, you will practice:

* Using the `prompt()` function
* Storing data in variables
* Using the modulus operator `%`
* Creating `if` and `else` statements
* Displaying messages with `alert()`
* Analyzing program execution using desktop tests
* Designing flowcharts

## Problem Description

Write a program that asks the user to enter a number.

The program must determine whether the number is even or odd and then
display the result to the user.

---

## Requirements

### Step 1

Ask the user to enter a number.

Example:

```text
Enter a number:
```

---

### Step 2

Store the value in a variable.

Example:

```javascript
var number;
```

---

### Step 3

Determine whether the number is even or odd.

Hint:

Use the modulus operator `%`.

A number is even when:

```javascript
number % 2 == 0
```

---

### Step 4

Display the result using an alert message.

Possible outputs:

```text
The number is even!
```

or

```text
The number is odd!
```

---

## Desktop Test

After writing your solution, create a desktop test.

Use the following format:

| Input | Condition Result | Output              |
| ----- | ---------------- | ------------------- |
| 3     | false            | The number is odd!  |
| 4     | true             | The number is even! |
| 5     | false            | The number is odd!  |
| 6     | true             | The number is even! |
| 7     | false            | The number is odd!  |

You may add additional test cases.

## Flowchart

Create a flowchart that represents the program logic.

Your flowchart should include:

```text
Start
↓
Ask for number
↓
Store number
↓
Is number % 2 == 0?
├─ Yes → Display "The number is even!"
└─ No  → Display "The number is odd!"
↓
End
```

You may create the flowchart using:

* Draw.io
* Lucidchart
* Excalidraw
* Hand-drawn diagram
