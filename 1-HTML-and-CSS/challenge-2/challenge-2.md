# Code Challenge: Create a Mini Software Development Blog

## Challenge Overview

In this challenge, you will create a simple HTML blog page about
Software Development.

The goal is to practice the fundamental HTML elements learned in class,
including headings, paragraphs, semantic tags, quotations, code blocks,
and page structure.

You must complete the missing sections of the provided template and add
your own content.

---

## Learning Objectives

By completing this challenge, you will practice:

- Creating a complete HTML document
- Using semantic HTML elements
- Working with headings and paragraphs
- Using text formatting tags
- Creating quotations with `<blockquote>`
- Displaying code with `<pre>` and `<code>`
- Organizing content with sections and articles
- Building a simple blog layout

---

## Requirements

Create a file named:

```text
index.html
```

Using the provided template, complete the following tasks.

### Header Section

Inside the `<header>` element:

1. Add a short description of the blog inside the empty paragraph.

Example topics:

- Learning software development
- Programming journey
- Technology and innovation
- Career growth in technology

---

### Main Article

Inside the first `<article>` element:

1. Keep the existing title and paragraph.

2. Add a motivational message inside the empty paragraph.

Your message should explain:

- Why learning programming is important
- How practice improves coding skills
- The benefits of becoming a developer

---

### Motivation Section

Inside the `<section>` element:

1. Complete the empty paragraph.

2. Explain why you enjoy learning Software Development.

You may include:

- Your personal goals
- Technologies you want to learn
- Projects you want to build
- Career aspirations

---

### Footer Section

1. Replace the author name with your own name.

---
