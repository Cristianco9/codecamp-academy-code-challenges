# Event-Driven Programming Challenges

## Welcome to the Event-Driven Programming Module

Congratulations on reaching the next stage of your JavaScript journey!

So far, you have learned how to write programs that execute from top to bottom 
using variables, conditionals, loops, functions, arrays, and objects. Those 
programs run once and then finish.

In modern web development, applications behave differently. They wait for 
**user interactions** and respond when something happens. This programming style 
is called **Event-Driven Programming**.

Instead of controlling the execution flow from beginning to end, your program 
listens for events such as:

- Mouse clicks
- Keyboard input
- Form submissions
- Button presses
- Mouse movement
- Scrolling
- Page loading

When one of these events occurs, JavaScript executes the corresponding function.

This model is the foundation of modern web applications built with JavaScript and 
is used extensively in frameworks such as React, Vue.js, Angular, and many others.
