# Code Challenge: Create a Technology Company Landing Page

## Challenge Overview

In this challenge, you will create a simple landing page for a
technology company using HTML and CSS.

The goal is to practice building a webpage structure and applying
styles using CSS class selectors. You will create a landing page for a
fictional company called TechNova.

You will complete the page by adding content sections and styling them
with CSS.

---

## Learning Objectives

By completing this challenge, you will practice:

* Creating a complete HTML document
* Linking an external CSS file
* Using semantic HTML elements
* Applying styles with CSS classes
* Working with typography and colors
* Organizing content into sections
* Building a simple landing page layout

---

## Requirements

Create the following files:

```text
index.html
homework-9.css
```

## HTML Structure

Build a landing page for a technology company.

### Header

The header must contain:

1. A company name

Example:

```text
TechNova
```

2. A company slogan

Example:

```text
Innovating Digital Solutions
```

Use the following classes:

```text
header
title
subtitle
```

---

## Main Content

Create a `<main>` element containing at least two sections.

### Services Section

Include:

1. A heading titled:

```text
Our Services
```

2. A paragraph describing the services offered by the company.

Example topics:

* Web development
* Mobile applications
* Software solutions
* Cloud services

Use the classes:

```text
section
section-title
text
```

---

### About Us Section

Include:

1. A heading titled:

```text
About Us
```

2. A paragraph describing the company.

Example topics:

* Company mission
* Team values
* Innovation
* Customer satisfaction

Use the classes:

```text
section
section-title
text
```

---

## Footer

Create a footer containing:

* A copyright message

Example:

```text
© 2026 TechNova
```

Use the classes:

```text
footer
footer-text
```
