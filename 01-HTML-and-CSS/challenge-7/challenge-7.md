# Code Challenge: Build a Company Web Page with CSS

## Challenge Overview

In this challenge, you will create a simple company web page using
HTML and CSS.

The goal is to practice building a structured web page and applying
basic CSS styles using class selectors. You will create a page for a
fitness company that introduces the business and explains its mission.

---

## Learning Objectives

By completing this challenge, you will practice:

* Creating a structured HTML page
* Linking an external CSS file
* Using CSS class selectors
* Applying colors and typography
* Styling headers, sections, and footers
* Organizing content with semantic HTML elements

---

## Requirements

Create the following files:

```text
index.html
challenge.css
```

---

## HTML Structure

Build a company page containing the following sections.

### Header

The header must contain:

1. A company name

Example:

```text
FitZone Gym
```

2. A company slogan

Example:

```text
Training for a healthier life
```

Use the following classes:

```text
header
title
subtitle
```

---

## Main Content

Create a main section containing two content sections.

### About Us Section

Include:

* A heading titled "About Us"
* A paragraph describing the company

Example topics:

* Services offered
* Company background
* Target customers

Use the classes:

```text
section
section-title
text
```

---

### Our Mission Section

Include:

* A heading titled "Our Mission"
* A paragraph explaining the company's mission

Example topics:

* Helping customers
* Improving health and fitness
* Providing professional guidance

Use the classes:

```text
section
section-title
text
```

---

## Footer

Create a footer containing:

* A copyright message

Example:

```text
© 2026 FitZone Gym
```

Use the classes:

```text
footer
footer-text
```
