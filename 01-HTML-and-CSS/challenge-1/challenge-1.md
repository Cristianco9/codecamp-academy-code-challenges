# Code Challenge: Build Your First HTML Registration Form

## Challenge Overview

In this challenge, you will create a complete **HTML Registration Form** using 
the concepts learned in class. The objective is to practice working with form 
elements, input fields, labels, buttons, and basic HTML structure while following 
good coding practices.

Forms are one of the most important parts of web development because they allow 
users to interact with websites by entering and submitting information.

Your task is to build a professional registration form using only **HTML**.

---

## Learning Objectives

By completing this challenge, you will practice:

- Creating an HTML document from scratch
- Using semantic HTML elements
- Working with the `<form>` element
- Creating labels and input fields
- Using different input types
- Organizing form sections
- Adding validation attributes
- Creating submit and reset buttons
- Improving accessibility with proper labels

---

## Technical Requirements

Your solution must include:

### Document Structure

```html
<!DOCTYPE html>
<html>
<head>
    <title>Registration Form</title>
</head>
<body>

</body>
</html>
```

### Form Features

- Use the `<form>` element
- Use a `<label>` for every form field
- Use appropriate input types
- Use placeholders where appropriate
- Mark required fields with the `required` attribute
- Group related information using headings

- Submit or reset the form
