# Challenge 13: Employee Profile Manager

## Introduction

Human Resources (HR) systems store detailed information about employees to
manage payroll, departments, contact information, work schedules, and job
assignments.

In JavaScript, this type of information is commonly represented using
**objects**, where each property describes a specific characteristic of an
employee.

In this challenge, you will practice **object modeling and data abstraction** by
creating a structured JavaScript object that represents an employee profile.

---

## Problem Description

A company is developing a Human Resources Management System (HRMS). One of the
first components of the system is an employee profile that stores all essential
information about each worker.

Your task is to analyze what information is important for an employee and
represent it using a well-organized JavaScript object.

---

## Requirements

Create a JavaScript object that satisfies the following requirements.

1. The object must represent **one employee**.

2. Include **between 12 and 20 meaningful properties**.

3. Include at least:

   - one nested object
   - one array property

4. Use appropriate data types:

   - strings
   - numbers
   - booleans
   - arrays
   - objects

5. Follow JavaScript naming conventions:

   - use camelCase
   - use descriptive property names

---

## Suggested Information

Your object may include information such as:

- employeeId
- firstName
- lastName
- age
- position
- department
- salary
- yearsOfExperience
- email
- phoneNumber
- employmentStatus
- skills
- certifications
- emergencyContact
- workSchedule
- officeLocation
- benefits
- hireDate

You may include additional properties if they improve the design.

---

## Expected Output

Your solution should contain:

- One well-structured JavaScript object
- Clean indentation and formatting
- Logical grouping of related information

---

## Evaluation Criteria

Your solution will be evaluated based on:

- Proper object organization
- Meaningful property names
- Correct use of JavaScript data types
- Effective abstraction of a real-world employee
- Code readability and consistency

---

## Bonus (Optional)

Enhance your solution by adding:

- A method that returns a formatted employee summary
- Multiple levels of nested objects
- Arrays containing certifications, projects, or technical skills

---

## Key Learning Outcome

By completing this challenge, you will practice how to:

- Model real-world entities using JavaScript objects
- Organize related information into nested structures
- Select appropriate data types
- Write clean and maintainable object definitions

---

## Submission Guidelines

- Save your solution in a `.js` file.
- Ensure your code runs without errors.
- Be prepared to explain your design decisions and why each property belongs to
  the employee profile.
