# Challenge 12: Library Book Catalog

## Introduction

Libraries and digital reading platforms store information about thousands of
books. Each book contains multiple attributes such as its title, author,
publication year, genre, and availability.

In software development, this type of information is commonly represented using
**JavaScript objects**, where each property describes an aspect of the real-world
entity.

In this challenge, you will practice **object analysis and abstraction** by
modeling a book as a well-structured JavaScript object.

---

## Problem Description

A library wants to digitize its catalog. Your task is to represent a single book
using a JavaScript object.

Before writing any code, analyze the information that a librarian or reader
would need to know about a book.

Then, organize that information using meaningful properties and appropriate data
types.

---

## Requirements

Create a JavaScript object that satisfies the following requirements.

1. The object must represent **one book**.

2. Include **between 12 and 20 meaningful properties**.

3. Include at least:

   - one nested object
   - one array property

4. Use appropriate data types:

   - strings
   - numbers
   - booleans
   - arrays
   - objects

5. Follow JavaScript naming conventions:

   - use camelCase
   - use descriptive property names

---

## Suggested Information

Your object may include information such as:

- title
- author
- publisher
- publicationYear
- genre
- language
- pageCount
- isbn
- price
- isAvailable
- rating
- keywords
- editions
- dimensions
- location
- borrowingHistory

You may include additional properties if they improve the model.

---

## Expected Output

Your solution should contain:

- One well-structured JavaScript object
- Clear indentation and formatting
- Logical organization of related information

---

## Evaluation Criteria

Your solution will be evaluated based on:

- Proper object structure
- Appropriate choice of properties
- Correct data types
- Good abstraction of a real-world book
- Clean, readable code

---

## Bonus (Optional)

Enhance your object by adding:

- A method that returns a formatted description of the book
- Multiple levels of nested objects
- Arrays containing related information such as genres, awards, or authors
