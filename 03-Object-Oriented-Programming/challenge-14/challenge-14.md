# Challenge 14: Online Store Product Catalog

## Introduction

E-commerce platforms manage thousands of products, each containing detailed
information such as its name, category, price, stock availability, technical
specifications, and customer ratings.

In JavaScript, this information is typically represented using **objects**.
Objects allow developers to organize related data into a single structure,
making applications easier to build and maintain.

In this challenge, you will practice **object modeling and abstraction** by
creating a JavaScript object that represents a product sold in an online store.

---

## Problem Description

An online shopping platform is building its product catalog. Every product must
store enough information for customers to browse, compare, and purchase items.

Your task is to analyze what information is important for a product and model it
using a well-structured JavaScript object.

Think carefully about what attributes a customer would expect to see when
viewing a product page.

---

## Requirements

Create a JavaScript object that satisfies the following requirements.

1. The object must represent **one product**.

2. Include **between 12 and 20 meaningful properties**.

3. Include at least:

   - one nested object
   - one array property

4. Use appropriate data types:

   - strings
   - numbers
   - booleans
   - arrays
   - objects

5. Follow JavaScript naming conventions:

   - use camelCase
   - use descriptive property names

---

## Expected Output

Your solution should contain:

- One well-structured JavaScript object
- Clean and readable formatting
- Logical grouping of related information

---

## Evaluation Criteria

Your solution will be evaluated based on:

- Appropriate abstraction of a real-world product
- Clear and descriptive property names
- Correct use of JavaScript data types
- Well-organized nested objects and arrays
- Code readability and consistency
